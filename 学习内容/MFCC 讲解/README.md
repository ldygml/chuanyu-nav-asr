# MFCC（梅尔频率倒谱系数）详解

## 一、一句话概括

MFCC 是把人耳听到的声音"翻译"成计算机能理解的数字矩阵。一段语音 → 一串 40 维的向量。

---

## 二、为什么需要 MFCC

原始音频是一个很长的波形数组（比如 1 秒 16kHz = 16,000 个数字），直接给模型太冗余了。MFCC 做了两件事：

1. **压缩**：1 秒 16,000 个采样点 → 100 帧 × 40 维 = 4,000 个数字
2. **提取关键信息**：只保留人耳能分辨的频率特征，丢掉噪音

---

## 三、提取过程（5 步）

```
原始波形 (1秒, 16000个采样点)
│
├── ① 分帧：切成 25ms 小段，每段 10ms 步进
│    → 100 个帧，每帧 400 个采样点
│
├── ② 加窗：每帧乘以汉明窗，消除边缘噪声
│
├── ③ FFT（快速傅里叶变换）：时域 → 频域
│    → 每帧得到一个频谱（各个频率的能量分布）
│
├── ④ Mel 滤波器组：模拟人耳对不同频率的敏感度
│    → 低频精细、高频粗糙，40 个 Mel 频率区间
│    → 每帧变成 40 维向量
│
└── ⑤ DCT（离散余弦变换）：去相关、压缩
     → 最终每帧 40 维 MFCC 特征
```

**结果**：1 秒音频 → (100, 40) 的矩阵

---

## 四、直观理解

| 步骤 | 做了什么 | 类比 |
|------|------|------|
| 分帧 | 切小段 | 把一部电影切成帧 |
| FFT | 看每帧含什么音高 | 看每帧画面的色彩分布 |
| Mel 滤波 | 按人耳敏感度加权 | 忽略肉眼看不清的细节 |
| DCT | 压缩特征 | JPEG 压缩 |

---

## 五、关键参数（我们用的）

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样率 | 16,000 Hz | 1 秒采 16,000 个点 |
| 帧长 | 25ms (400 点) | 每帧包含的音频长度 |
| 帧移 | 10ms (160 点) | 相邻帧的重叠步进 |
| Mel 滤波器数 | 40 | 每帧输出的特征维度 |
| MFCC 维度 | 40 | 最终特征向量大小 |

---

## 六、在 TeleSpeech-ASR 中的作用

```
WAV 文件 → MFCC 提取（torchaudio/Kaldi）
         → .ark 文件存储 (3GB)
         → Data2Vec 模型输入
         → 文字输出
```

模型吃的不是原始 WAV，是预提取好的 MFCC。所以即使原始音频丢了，只要 MFCC 还在，训练就不受影响。

---

## 七、为什么用 MFCC 而不是原始波形

| | 原始波形 | MFCC |
|------|------|------|
| 数据量 | 16,000/s | 4,000/s (压缩 75%) |
| 噪声 | 包含环境噪声 | 滤掉大部分噪声 |
| 人耳一致性 | 线性频率 | Mel 刻度（模拟人耳） |
| 计算效率 | 低 | 高 |
