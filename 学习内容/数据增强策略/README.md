# 语音数据增强策略

## 一、速度扰动（Speed Perturbation）

本项目使用的核心增强方法。

### 原理

```
原始音频 → SoX tempo 变速 → 快/慢版本（音高不变）
```

| 速度 | 效果 | 数据量 |
|:--:|------|:--:|
| 1.0x | 原始 | 1× |
| 0.9x | 慢 10% | +1× |
| 1.1x | 快 10% | +1× |

### SoX 命令

```bash
sox input.wav output_sp0.9.wav tempo 0.9
sox input.wav output_sp1.1.wav tempo 1.1
```

### 效果

导航数据：3,385条 → 10,155条，CER **6.28% → 4.93%**（-1.35pp）

### 为什么有效

- 同一句话不同语速，文本不变，模型学到速度不变性
- 模拟真实场景中说话快慢的差异
- 零成本（不需要额外标注）

## 二、其他可用增强方法

| 方法 | 工具 | 效果 | 是否使用 |
|------|------|------|:--:|
| 加背景噪声 | SoX / torchaudio | 鲁棒性 | 未用 |
| 音量扰动 | SoX vol | 鲁棒性 | 未用 |
| SpecAugment | Fairseq 内置 | 频域/时域 mask | 默认开启 |
| 房间混响 | pyroomacoustics | 鲁棒性 | 未用 |

---

## 三、数据增强在本项目的效果

| 配置 | 导航 CER |
|------|:--:|
| 纯导航 3.2k (无增强) | 6.28% |
| 增强导航 13k (变速×3) | **4.93%** |

数据量翻 4 倍，CER 降 1.35pp。是导航赛道最大单次提升。
