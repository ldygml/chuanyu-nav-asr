## 二、软件环境

### 2.1 Conda 环境

```bash
# 创建环境
conda create -n chuanyu-ASR python=3.8
conda activate chuanyu-ASR

# 确认版本
python --version   # 3.8.20
```

### 2.2 核心依赖安装

```bash
# PyTorch（CUDA 11.7 版本）
pip install torch==1.13.0+cu117 \
    torchaudio==0.13.0+cu117 \
    torchvision==0.14.0+cu117 \
    -f https://download.pytorch.org/whl/torch_stable.html

# Fairseq（源码安装）
git clone https://github.com/facebookresearch/fairseq
cd fairseq
pip install --editable ./

# 其他依赖
pip install kaldiio==2.18.1 \
    timm==1.0.28 \
    soundfile==0.13.1 \
    editdistance==0.8.1 \
    sentencepiece \
    tensorboardX \
    pyyaml>=5.1
```

## 五、运行说明

### 5.1 训练

```bash
cd ASR/data2vec_dialect
source path.sh
conda activate chuanyu-ASR
bash run_scripts/run_d2v_finetune.sh
```

### 5.2 推理

```bash
bash run_scripts/decode.sh
```

### 5.3 评测

```bash
python eval_official.py <checkpoint_path>
```

### 5.4 完整工作流

```bash
# 1. 数据准备：WAV → MFCC → data.list
# 2. 训练：run_d2v_finetune.sh
# 3. 推理：infer.py
# 4. 规范化：normalize.py
# 5. 评分：score.py
```

## 六、常见问题

| 问题 | 解决 |
|------|------|
| FP16 gradient overflow | 设置 common.fp16=false 用 FP32 |
| OOM | 降低 dataset.max_tokens |
| ModuleNotFoundError: examples | source path.sh 设置 PYTHONPATH |
| 数据盘丢失 | 重启后检查挂载，MFCC 离线提取不受影响 |
