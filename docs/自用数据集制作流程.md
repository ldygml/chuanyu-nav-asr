## 二、Chuan-Yu-dialects 制作流程

### 2.1 数据来源

从开源数据集 **KeSpeech** 中抽取：
- 目录：`phase1/` 下所有说话人
- 筛选：成都话、重庆话
- 规模：35,793 条

### 2.2 数据组织

```
Chuan-Yu-dialects/
├── 1000005/
│   └── phase1/
│       ├── 1000005_0e4c205e.wav
│       ├── 1000005_145adf99.wav
│       └── ...
├── 1000008/
│   └── phase1/
│       └── ...
└── phase1.text          # 全量标注
    # 格式: utt_id<TAB>转录文本
    # 1000005_0e4c205e 该行将推出无卡化时代电子支付
```

### 2.3 制作步骤

#### 步骤 1：生成 wav.scp

```python
# 遍历所有说话人目录，收集 WAV 路径
for speaker in speakers:
    for wav in glob(f'{speaker}/phase1/*.wav'):
        f.write(f'{utt_id}\t{wav_path}\n')
```

#### 步骤 2：提取 MFCC 特征

```python
import torchaudio

mfcc = torchaudio.transforms.MFCC(
    sample_rate=16000,      # 16kHz
    n_mfcc=40,              # 40 维
    melkwargs={
        'n_mels': 40,       # 40 个 Mel 滤波器
        'n_fft': 512,       # FFT 点数
        'win_length': 400,  # 25ms 帧长
        'hop_length': 160,  # 10ms 帧移
        'f_min': 40,        # 低频
        'f_max': 7800,      # 高频
        'window_fn': torch.hamming_window
    }
)

# 每条音频 → (帧数, 40) 矩阵
feats = mfcc(waveform).squeeze(0).transpose(0, 1).numpy()
```

#### 步骤 3：存储为 Kaldi ARK 格式

```python
import kaldiio
kaldiio.save_ark('mfcc.1.ark', {utt_id: feats}, scp='mfcc.1.scp')
```

#### 步骤 4：生成 data.list

格式（Tab 分隔）：
```
utt:1000005_0e4c205e
feat:/path/mfcc.1.ark:17
feat_shape:690,40
text:该行将推出无卡化时代电子支付
token:该 行 将 推 出 无 卡 化 时 代 电 子 支 付
tokenid:[5858,5669,1620,...]
token_shape:14,7531
```

#### 步骤 5：数据集划分

```python
import random
random.seed(42)
# 35,793 → train 35,093 / dev 500 / test 200
```

## 三、导航增强数据集制作流程

### 3.1 数据来源

比赛官方提供的 **导航训练集**（3,385 条）：
```
SichuanDialectNavigation-TrainingDataset/
├── SPKINFO.txt
├── UTTERANCEINFO.txt    # 标注
└── WAV/
    └── G0039/
        ├── G0039_0_S1001.wav
        └── ...
```

### 3.2 标注解析

```python
# UTTERANCEINFO.txt 格式（TSV 6列）
# CHANNEL  UTTRANS_ID  SPEAKER_ID  PROMPT  PROMTTYPE  TRANSCRIPTION
# C0  G0039_0_S1001.wav  G0039    Navigation  我明天上午9点要从...
```

生成：
- `wav.scp`：utt_id → wav 路径
- `text`：utt_id → 转录文本

### 3.3 数据增强（速度扰动）

```bash
# 原始
cp input.wav output_sp1.0.wav

# 慢速 0.9x
sox input.wav output_sp0.9.wav tempo 0.9

# 快速 1.1x
sox input.wav output_sp1.1.wav tempo 1.1
```

结果：
```
3,385 原始 × 3 速度版本 ≈ 10,155 条
+ 原始 3,385 = 13,540 条
```

### 3.4 后续处理

与 Chuan-Yu-dialects 相同：
1. 提取 MFCC（同参数）
2. 生成 data.list
3. 划分：train 13,240 / dev 300
