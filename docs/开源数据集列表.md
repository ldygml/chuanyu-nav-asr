# 开源数据集与资源列表

## 一、比赛相关数据

### 1.1 导航训练集（官方提供）

| 项目 | 说明 |
|------|------|
| 名称 | SichuanDialectNavigation-TrainingDataset |
| 规模 | 3,385 条 |
| 内容 | 川渝方言语音导航指令 |
| 标注 | UTTERANCEINFO.txt（TSV 格式，含 TRANSCRIPTION 列） |
| 特点 | 出发地/目的地/途经点/路线偏好等导航要素密集 |
| 使用 | 比赛核心训练数据 |

**标注格式示例：**
```
CHANNEL  UTTRANS_ID       SPEAKER_ID  PROMPT     TRANSCRIPTION
C0       G0039_0_S1001.wav G0039       Navigation 我明天上午9点要从什邡市方亭街道办出发，打7座商务车去什邡市人民医院...
```

### 1.2 川渝方言数据集（官方提供）

| 项目 | 说明 |
|------|------|
| 名称 | 四川官方方言数据集（12 城市） |
| 规模 | 13,068 条 |
| 城市 | 成都、重庆、乐山、宜宾、泸州、西昌、内江、自贡、雅安、广安、达州、南充 |
| 标注 | UTTERANCEINFO.txt + SPKINFO.txt |
| 使用 | 通用方言模型训练（备用） |

### 1.3 Chuan-Yu-dialects（自用数据集）

| 项目 | 说明 |
|------|------|
| 来源 | 从开源数据集 **KeSpeech** 抽取 |
| 抽取规则 | phase1 目录下所有成都话和重庆话 |
| 规模 | 35,793 条 |
| 标注 | phase1.text（utt_id + 转录文本） |
| 使用 | 通用川渝方言模型训练 |

## 二、开源模型

### 2.1 TeleSpeech-ASR（TeleAI）

| 项目 | 说明 |
|------|------|
| 发布方 | 中国电信人工智能研究院（TeleAI） |
| 仓库 | https://github.com/Tele-AI/TeleSpeech-ASR |
| 预训练 | 30 万小时无标注多方言语音 |
| 许可证 | 星辰语音模型社区许可协议 |

### 2.2 使用到的模型文件

| 模型 | 参数 | 大小 | 说明 |
|------|:--:|:--:|------|
| large.pt | 0.3B | 4.7G | Data2Vec 2.0 预训练模型 |
| finetune_large_kespeech.pt | 0.3B | 3.6G | KeSpeech 8 方言微调模型（比赛基座） |
| base.pt | 0.09B | 1.4G | 小规模预训练模型 |
| kespeech_encoder.pt | 0.3B | 1.2G | 从微调模型提取的 encoder |

### 2.3 KeSpeech 数据集

| 项目 | 说明 |
|------|------|
| 名称 | KeSpeech |
| 发布方 | TeleAI |
| 内容 | 8 种方言的标注语音数据 |
| 用途 | 微调 finetune_large_kespeech.pt 模型 |
| 本队使用 | 抽取 phase1 成都话+重庆话构成 Chuan-Yu-dialects |

## 四、数据使用合规声明

1. 所有比赛官方数据仅用于本次比赛训练与评测，遵守数据使用与保密协议
2. Chuan-Yu-dialects 来源于开源数据集 KeSpeech，抽取后用于模型微调
3. 增强数据（变速扰动）基于官方导航数据自生成，不涉及外部数据
4. 所有第三方代码、模型、数据均已在上文标注来源
